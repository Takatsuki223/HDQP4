# 水文数据查询程序4（Hydrological data query program4）   
- 一个基于**Python + BeautifulSoup + ECharts**的便携化河道水位数据爬取与可视化展示分析程序。   
- 供**梧州仓码**同事使用，快速查询梧州航道水位信息，为船舶调度提供依据。 
- 是**水文数据查询程序3**的**升级版**，水文站点的数据源增加了6个站点的逐时水位数据。  
  
## 主要功能   
**1.** 爬取广西水运发展中心每日发布的官方航道水情信息，涵盖梧州仓码上游西江流域内1个水文站点与3个通航水利枢纽早上8点的水位相关数据。   
**2.** 爬取广西壮族自治区水利厅水情网站的逐时水位数据，涵盖梧州仓码上游西江流域内6个水文站点逐时水位数据。   
**3.** 存储每日的航道水位与水利枢纽相关数据到本地，本地化持久存储。   
**4.** 将爬取到的航道水位数据可视化展示，并做分析。   
**5.** 对爬取到的水位数据进行分析，并进行相关预警信息的显示，包含高水位、水位超警、放水、大流量、快速涨水与低水位预警。  
**6.** 可以显示哪些水文站点和大坝的数据被成功爬取，及时了解程序运行情况。   
**7.** 支持将.py文件打包为.exe程序，可以在其他电脑更方便的使用。   

## 使用说明（打包后）   
**所有操作仅在"dist"文件夹内操作使用即可，请先确保river.jpg、water_level_data.json、realtime_water_level.json在dist文件夹内！**    
**1.** 打开文件夹（名为“dist”的文件夹）后，**双击运行"水位数据爬取.exe"文件。**    
**2.** 会打开一个终端页面，**请耐心等待10秒左右**，程序会开始自动运行。      
**3.** 程序开始自动运行后，**终端页面会输出水位信息以及运行情况**，可以通过终端判断是否运行正常。    
**4.** 运行完成后，终端会自动关闭。并且**会在程序同文件夹内生成一个"water_level_report.html"网页文件，双击打开（用浏览器打开）即可查看可视化报告。**

## 注意事项   
- **可视化报告在程序同文件夹内，文件名为water_level_report.html。**   
- **为达到最佳展示效果，请将浏览器窗口扩展至全屏查看可视化报告。**   
- **数据缺失问题1：早八点梧州水位与水库枢纽数据源链接为https://www.gxghj.cn/c/fw/slcx   打开后看到的当天发布的链接中，只要缺少梧州、贵港2个航道水情信息的任意一个链接，就会影响数据爬取，导致数据缺少。**     
- **数据缺失问题2：逐时水位数据源为http://slt.gxzf.gov.cn/page/index.html?act=3  爬取耗时可能较长**

## 本地部署

### 环境要求
- **Python 3.8+**
- **BeautifulSoup 4.12+**
- **Requests 2.31+**
- **PyInstaller 6.22.2（如有打包需求才需要配置）**

### 部署操作

**1. 克隆项目**
```
# 复制以下命令到终端执行
git clone https://github.com/Takatsuki223/HDQP4.git

#进入目录
cd hdqp4
```

**2. 安装依赖**
```
# 安装依赖
pip install -r requirements.txt
```
**3. 启动程序**
```
# 运行脚本 可以查看运行结果 输出可视化报告
python screenshot.py
```

**4. 打包为程序**
```
#打包成exe程序 会在目录生成dist和build两个文件夹，在dist文件夹内输出exe程序。
python -m PyInstaller screenshot.spec

# 复制流域图、数据文件以及程序使用说明复制到dist文件夹内（必做！否则可视化报告会出错！）
cp @("river.jpg", "water_level_data.json", "realtime_water_level.json", "使用说明(用前必看！).txt") dist 
```
## 项目架构

```
hdqp4/
├── screenshot.py              # 主程序脚本（爬取、解析、存储、生成报告）
├── screenshot.spec            # PyInstaller 打包配置文件
├── requirements.txt           # Python 依赖列表
├── water_level_data.json      # 水位与枢纽每日早八点数据（本地持久化存储）
├── realtime_water_level.json  # 水位与枢纽实时数据（本地持久化存储）
├── water_level_report.html    # 可视化分析报告（程序运行后生成）
├── river.jpg                  # 流域示意图（报告内嵌图片）
├── README.md                  # 项目说明文档
├── guigang.png                # 贵港那边的下载图片 OCR用
└── 使用说明(用前必看！).txt     # 打包后供同事查看的说明文档
```
